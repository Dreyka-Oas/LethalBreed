# Third-party components

The LethalBreed jar bundles the library below (Fabric Jar-in-Jar, under
`META-INF/jars/`). It keeps its own licence — [LICENSE](LICENSE) does not apply
to it, and this notice must travel with any copy of the jar.

Fabric Loader and Fabric API are *not* listed here: they are required at runtime
and are never bundled.

## JOCL 2.0.5 — `org.jocl:jocl:2.0.5`

Java bindings for OpenCL, used by the GPU compute path. <http://jocl.org>
